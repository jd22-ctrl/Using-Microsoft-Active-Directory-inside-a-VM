# Organizational Units (OUs)

## Objective

The objective of this task was to create Organizational Units (OUs) within Active Directory to organize users, computers, and other directory objects into a logical structure. Organizational Units simplify administration by allowing administrators to delegate control and apply Group Policy Objects (GPOs) to specific groups of objects.

## Actions Performed

* Opened **Active Directory Users and Computers (ADUC)**.
* Created Organizational Units for different departments or administrative purposes.
* Assigned clear and descriptive names to each OU.
* Verified that each Organizational Unit was created successfully within the domain hierarchy.

## Outcome

The Organizational Units provide a structured environment for managing Active Directory resources. This organization improves administrative efficiency, supports delegated management, and enables targeted Group Policy application.
