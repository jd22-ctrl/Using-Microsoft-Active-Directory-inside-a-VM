# Active Directory Administration Lab

## Overview
This project demonstrates fundamental Active Directory administration tasks performed in a Windows Server lab environment.

## Skills Demonstrated

- Creating Active Directory users
- Creating Organizational Units (OUs)
- Creating Security Groups
- Assigning users to Security Groups
- Creating and linking Group Policy Objects (GPOs)
- Moving computer accounts into Organizational Units

## Folder Structure

| Folder | Description |
|---------|-------------|
| 01-Create-Users | Creating Active Directory user accounts |
| 02-Organizational-Units | Creating Organizational Units |
| 03-Security-Groups | Creating Security Groups |
| 04-Assign-Users-to-Groups | Adding users to Security Groups |
| 05-Group-Policy | Creating Group Policy Objects |
| 06-Link-GPO | Linking GPOs to Organizational Units |
| 07-Move-Computer-to-OU | Moving computer accounts into the correct OU |
| 08-Resetting-Passwords | Helping users log into their accounts |
| 09-Disabled-Accounts   | Helping users recover disabled accounts

## Environment

- Windows Server
- Active Directory Domain Services (AD DS)
- Group Policy Management
- Active Directory Users and Computers (ADUC)

## Purpose

This lab demonstrates core Active Directory administrative tasks commonly performed by Systems Administrators and Help Desk professionals.
