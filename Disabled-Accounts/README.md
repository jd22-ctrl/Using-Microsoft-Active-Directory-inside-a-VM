## Repairing a Disabled User Account

### Description

This task demonstrates how to restore access for a user whose Active Directory account has been disabled. Re-enabling a disabled account is a common responsibility for IT support and help desk technicians when users are unable to sign in due to administrative restrictions.

### Steps Performed

1. Opened **Server Manager** and selected **Tools**.
   <img width="1024" height="768" alt="VirtualBox_tt_17_07_2026_17_55_00" src="https://github.com/user-attachments/assets/06f6b57e-5ba9-40d2-a799-7859e92de560" />

2. Launched **Active Directory Users and Computers (ADUC)**.
<img width="1024" height="768" alt="VirtualBox_tt_17_07_2026_17_55_07" src="https://github.com/user-attachments/assets/8c4ec16b-7a62-49e9-ba0a-f19035b1cf6b" />

3. Right-clicked the domain (forest) and selected **Find**.
<img width="1024" height="768" alt="VirtualBox_tt_17_07_2026_17_55_19" src="https://github.com/user-attachments/assets/2a575065-f411-46f9-ba66-056965196550" />

4. Entered the user's name in the search field and clicked **Find Now**.
5. Located the user account in the search results displayed at the bottom of the window.
6. Right-clicked the disabled user account and selected **Enable Account**.

<img width="1024" height="768" alt="VirtualBox_tt_17_07_2026_17_55_190" src="https://github.com/user-attachments/assets/ec698f95-11af-4e7b-a101-4dfac759ed61" />

8. Verified that the account was successfully re-enabled, allowing the user to sign in again.

### Result

The user's Active Directory account was successfully re-enabled, restoring access to domain resources. This exercise demonstrates proficiency with common account administration tasks performed by entry-level IT support professionals using Active Directory Users and Computers.
